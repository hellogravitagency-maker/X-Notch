# Theme Studio Plugin for X-Notch

Curated dynamic color themes, glowing ambient accent palettes, and one-click styling presets for X-Notch.

## Presets Included
- ⚡ **Cyberpunk Neon** (`#00F0FF` / `#0A0E1A`)
- 🌌 **Aurora Borealis** (`#00FFA3` / `#0E1524`)
- 🌅 **Sunset Gold** (`#FF8C00` / `#1C0B12`)
- ⬛ **OLED Pure Black** (`#007AFF` / `#000000`)
- 💻 **Matrix Terminal** (`#00FF66` / `#041407`)
- 🔮 **Liquid Lavender** (`#C084FC` / `#170F2C`)

## Features
- **Closed Notch Pill**: Dynamic glowing jewel reflecting the active palette.
- **Expanded Card**: Interactive theme cards with instant real-time live preview.
- **Configurable**: Configurable startup preset inside the built-in Plugin Manager.
