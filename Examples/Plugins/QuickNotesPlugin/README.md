# Quick Notes Plugin for X-Notch

Instant scratchpad and markdown/todo notes widget integrated right inside the X-Notch Dynamic Island.

## Features
- **Compact Resting Pill**: Shows `📝` along with a live preview of the first line of your note.
- **Expanded Card**: Multi-line scratchpad with auto-save to disk, character and word counters.
- **Action Toolbar**:
  - 📋 **Copy**: Copies note to Windows clipboard in 1 click.
  - ☑ **Todo**: Automatically inserts markdown checklist checkbox `- [ ] `.
  - ⏱ **Timestamp**: Inserts current time `[hh:mm AM/PM]`.
  - 🗑️ **Clear**: Clears note.
- **Persistence**: Saved automatically to `%APPDATA%\X-Notch\Plugins\com.xnotch.quicknotes\quicknotes.txt`.
- **Configurable**: Configurable font size in Plugin Manager.
