| `#US` string heap | **absent** | **absent** |
| Strong name | none | none |

- Host: `NotchPixel.exe` is a 300 KB apphost; the code lives in the DLLs.
- **Obfuscation:** most types sit in 1-letter namespaces (`n`, `f`, `X`, `Z`, `b`, `C`), about 1,400 types. The whole `#US` heap is stripped, so every C# string literal is encrypted and decoded at runtime (31 `FieldRVA` blobs in the app and 30 in Core hold the data). Static string search finds nothing.
- **Names that survive:** enums and `record` DTOs, because the JSON serializer and settings binder need them. That gives an almost complete domain model (section 3).
- Updater: **Velopack 1.2** is referenced, but Store builds update through MSIX.

## 3. Domain model (recovered enums and DTOs)

### Island core (`Scene`, root)
- `IslandMode`: Idle, Compact, Expanded, Slim, Hud, Overlay, Hidden
- `IslandShape`: Island, Notch · `IslandPosition`: Center, Left, Right, LeftEdge, RightEdge · `IslandSide`/`Motion.IslandEdge`: Top, Left, Right(, Bottom)
- `CardPanel` (expanded tabs): Media, Shelf, Clipboard, Widgets, Call, Tiles, Phone, Controls, Launcher, Notifications, Web, Chat, Agents, Deck
- `LiveActivity`: Download, Export, Call, Recording, Agent
- `HudKind`: Volume, Brightness, Charging, Unplugged, LowBattery, DeviceConnected/Disconnected, Notification, Welcome, TimerDone, Copied, MicMuted, MicLive, DownloadDone, Color, Reminder, LockKey
- `IslandHit`: more than 30 hit-test zones (PlayPause, Progress, ShelfItem, sliders, toggles and so on). Hit testing is custom; the Skia scene has no WPF controls.
- `AppBehaviour`/`Rules.RuleBehaviour`: Normal, Slim, Hide, Game (per-app rules)
- `Rules.IslandSurface`: Theme, Black, Clear · `StripBackground`: Black, Glass, None · `WindowsGpuChoice`
- Icons: Lucide icon set (`LucideIcon`, about 55 glyphs) drawn as vectors in Skia

### Widgets (`Core.Widgets`)
`WidgetTiles`: Date, Timer, Weather, Stats, Clock, Todo, Photos, Battery, DayClock, Note, Countdown, Calculator, Currency, Website, Ping, PlayTime, ScreenTime, Air, Sun, Progress

- `TimerPhase`: Focus/Break (Pomodoro) · `ReminderRepeat` · `AirBand` (AQI) · `PingQuality` · `ControlTile` (WiFi, BT, NightLight, Focus, Mute, Battery, Output, Mic, Input)

### Media
- `PlaybackState` (GSMTC) · `LyricsQueryKind` Get/Search/Anywhere: synced lyrics lookup (likely LRCLIB-style)
- Visualizer: WASAPI loopback · `ReplaceVolumeFlyout` hides the native XAML volume pill

### Integrations
- `ChatPlatform`: Twitch, YouTube. Raw Twitch IRC parsing (`TwitchLineKind` PING/PRIVMSG/CLEARCHAT…) feeds a chat overlay.
- OBS WebSocket (`ObsEnabled/Port/Password`)

### AI Agents (`Core.Agents`), new since the earlier notes
- `AgentKind`: **Claude, Codex, Hermes, Antigravity, Custom**
- `AgentState`: Listening, Working, Waiting, Done, Error
- `AgentSignalKind`: Start, Prompt, Tool, Waiting, Done, Error, End, Idle (the hook lifecycle)
- `AgentToolKind`: Thinking, Editing, Reading, Command, Searching, Web, Subagent, Planning, Asking
- `KeyStepKind`: Type, Enter, Escape, Pause. NotchPixel **types replies into the agent's terminal** (UI strings: "Answer it in its terminal; nothing was typed", "Could not type into its terminal").
- How it works: it installs CLI hooks that POST to the local notify endpoint `127.0.0.1:47823`. Evidence: `~/.claude/settings.json.notchpixel-backup` (838 B, a backup NotchPixel wrote before it edited the file). Today's `~/.claude/settings.json` holds no NotchPixel hook commands, so the hooks were removed or never kept.

### Phone: "PC Deck" (`Core.Deck`)

## 4. Frontend layers

### 4a. Island and cards (desktop): no XAML
The island is one Skia scene drawn into a DirectComposition swapchain. WPF hosts only the Settings window. Every visual (pills, cards, sliders, Lucide icons, Geist text) is drawn by hand, and input goes through the `IslandHit` hit-test enum. This is why the v0.5.113 notes found almost no XAML/BAML.

### 4b. PC Deck (phone): embedded web app served by HttpListener
Files: `index.html` (5.8 KB), `app.js` (14 KB), `pad.js`, `pages.js`, `splash.js`, `haptics.js`, `style.css` (25 KB). Plain JS, no framework. It installs as a PWA ("PC Deck by NotchPixel", apple-mobile-web-app).

Pages: **Now playing** (art, seek, transport, volume, meters) · **Trackpad** (tap to click, two-finger scroll or right-click, type-to-PC form, 500 characters max) · **Apps** (editable launcher) · **Modes** (Game meters and keys, Present clock).

REST API (bearer token):

| Endpoint | Purpose |
|---|---|
| `POST /api/pair`, `GET /api/pair/poll` | pairing handshake |
| `GET /api/status` | DeckStatus telemetry |
| `GET /api/deck` | actions and layout |
| `GET /api/art` | album art (versioned by `ArtVersion`) |
| `POST /api/action` | run a DeckAction |
| `POST /api/seek`, `/api/volume` | media control |
| `POST /api/mouse`, `/api/type` | remote input (SendInput) |
| `GET /api/apps/choices`, `POST /api/apps/add`, `/api/apps/remove` | launcher editing |
| `POST /api/phone/battery` | phone battery shown on the PC island |

Separate listener: `http://127.0.0.1:47823/notify` (loopback only). Agents, scripts and "From your phone" notices use it.

## 6. Runtime observations (log)
- Occlusion loop: "Island was under another window; put back on top" about once per second while covered. This is polling, not event-driven, and is a target for X-Notch's zero-idle-CPU goal.
- Settings window is prebuilt in the background ("ready in the background in 1886 ms") and then released.
- If a hotkey is taken, it falls back (`Ctrl+Alt+M` → `Ctrl+Alt+Shift+M`).
- GPU: runs on Intel Iris Xe; DDC/CI found 0 external monitors.

## 7. Takeaways for X-Notch (clean-room)
1. Copy the **architecture**, not the code: a single composited GPU scene plus a hit-test enum avoids WPF layout cost for the island.
2. The **Agents** card (Claude/Codex hooks → local endpoint → live activity → reply by typing into the terminal) is the most novel feature. It is worth a clean implementation through hook config that X-Notch writes itself.
3. **Phone Deck** with token-hash pairing, a public-network refusal and a firewall rule is a solid security model to match.
4. Beat it on idle cost: replace the occlusion polling with `SetWinEventHook` (EVENT_SYSTEM_FOREGROUND / LOCATIONCHANGE) only.
5. Localization: 21 languages with English-string keys, a simple and effective scheme.

## Limits
- No C# decompile: ReadyToRun plus obfuscation make method bodies opaque, and string literals are encrypted. Behaviour details come from enum names, UI strings, the log and P/Invoke names.
- REA's managed-members view does not select fields, so the full type pages were dumped locally rather than inline.
